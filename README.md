# Color Catcher (Vercel-ready)

A tiny browser game where players click moving color targets before the timer runs out.

## Run locally

```bash
python3 -m http.server 8080
```

Open <http://localhost:8080>.

## Deploy on Vercel (from GitHub)

1. Create a new GitHub repository and push this project.
2. In Vercel, choose **Add New → Project**.
3. Import your GitHub repository.
4. Keep default settings (no framework preset needed).
5. Click **Deploy**.

Vercel will serve `index.html` as a static site.
